# 初始需求：展台供电安全采录台

会展配电员必须在离线、来源可能迟到的条件下协调展商负荷、共享相位容量、实际峰值和复位审批。四本账分别保存原始证据、当前决定与历史状态，彼此可独立运行。

1. 展商负荷契约账核场馆签约范围与展期；未由配电员签核的增容保持原已承诺上限，正式签核后旧资源分配须重审。
2. 回路容量账按同相位重叠峰值和断路器容量排程，落选有候补记录；改时段先验证新方案，失败时不得丢失旧确认分配。
3. 电表证据账核电表身份、校准时刻、累计值与更换见证。短时高峰仅观察，三次连续可信超限才确认过载；无交接的负增量不能证明过载已结束。
4. 断电复位责任账要求配电盘和现场员独立见证跳闸；整改人与审批人分离，冷却与三次正常复测齐全后才能复电。最终许可同时核对契约、回路、电表与跳闸状态，旧许可在任一前提失效时撤销。

导入与决定应由 SQLite 事务提交；重试不能重复占容量或审批。JSON 报告应列证据哈希、版本引用、候补原因及安全状态。所有 fixture 均为虚构数据。
